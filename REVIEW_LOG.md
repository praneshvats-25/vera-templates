# Review log

What Claude Code proposed, what was wrong with it, and what I chose instead.
[NOTES.md](NOTES.md) is the one-page summary. This is the full list, in the order it happened.

## How I ran the work

- **Context before code.** The AI read the whole brief and every Figma screen first, and looked up current standards in the official documentation. I told it not to copy conventions from an older repo of mine.
- **Questions before assumptions.** I told it to ask me about every case the brief leaves open instead of guessing. My answers are in section 1.
- **A plan before code.** I sent the plan back five times (sections 2 to 6). Nothing was built until I approved it.
- **Two pull requests.** "Browse and copy templates", then "Edit and publish a copy". Each edge case lives in the pull request that owns the behaviour.
- **Approval for every step.** Before each commit I saw the exact files and the test results. I asked for each commit to be checked on its own in an empty folder (install, lint, types, tests, build). I approved each push, pull request and merge separately.
- **House rules.** Simple code. A short description at the top of every file. Tailwind theme tokens, no one-off values. One way of doing each thing, everywhere. Nothing described as "passed" before it ran.
